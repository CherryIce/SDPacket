# Home More Panel Visual Specification

This specification records the user-approved direction for the home-screen More panel.

- Keep the panel as a native bottom sheet with a system dimming layer and drag handle.
- Use the same warm ivory surface, forest-teal accents, 20-point horizontal margins, soft outlines, and rounded geometry as the selected home screen.
- Add a clear `More actions` title above one grouped card.
- Present `Archived projects` and `Settings` as two compact, fully tappable, left-aligned rows.
- Give each row a mint rounded-square icon container, a dark label, and a trailing chevron.
- Separate the rows with one subtle inset divider.
- Keep `Cancel` as a quiet secondary action below the card.
- Preserve the existing actions and destinations; do not add new behavior.
- Allow the content to scroll on short screens or with enlarged system text rather than overflowing.
