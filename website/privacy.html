01

政策范围

本隐私政策适用于“搬家箱”（以下简称“本应用”）以及本应用的静态官网。文中的“我们”指正式发布前在“联系我们”中填写的开发者或运营者。

本应用帮助用户在搬家过程中建立项目与箱子记录、拍摄或选择箱体照片、维护物品与位置、生成二维码标签、推进搬运状态、离线搜索并导出或备份资料。

当前版本不要求创建账号，不提供开发者云同步，也未接入广告、行为分析或第三方 AI 服务。核心搬家记录默认保存在用户设备上。

03

使用方式与本地存储

本应用在设备上处理上述信息，用于创建、编辑、搜索和展示搬家项目及箱子记录；分配项目内唯一箱号；维护物品、房间、位置、搬运状态和异常；生成二维码、PNG、CSV 与 PDF；以及创建、校验和恢复本地备份。

结构化记录以 JSON 快照保存在应用支持目录，应用写入时使用临时文件，并保留上一份本地备份。照片副本保存在同一应用管理目录下。这里的“备份”均指本地文件机制，并不代表自动云备份或开发者服务器同步。

系统权限

▣

相机

仅在用户主动拍摄箱体照片或扫描本应用格式的二维码标签时使用。拒绝后仍可选择照片、手动登记和文字搜索。

照片

◉

麦克风

仅在用户主动开始语音登记时采集语音，供系统语音识别生成可编辑文字。本应用不长期保存原始音频。

⌁

语音识别

仅在用户选择语音登记时请求。拒绝或不可用时，可直接切换到手动文字登记。

当前 iOS 配置未声明定位、通讯录、通知或跨应用跟踪权限。Android 当前声明相机、录音和网络权限；核心记录流程不因此自动向开发者服务器上传项目、箱子、照片或物品清单。

05

语音识别的特殊说明

本应用会向系统语音能力请求“设备端识别”模式，但不同设备、系统、语言和语音服务提供方的实际支持情况不同，不能保证所有语音识别都完全离线完成。系统或设备上的语音识别服务可能按照其自身隐私政策处理音频和识别结果。

本应用本身不保存原始录音。识别出的文字会先显示为可编辑内容，只有在用户确认创建箱子记录后，才作为备注写入本地数据。语音不可用不会影响拍照、手动登记、搜索、二维码和其他核心功能。

06

导出、打印、备份与分享

二维码 PNG、单个或 A4 标签 PDF、项目收尾 PDF、CSV 与版本化 ZIP 备份包均由本应用在设备上生成。完整备份可包含项目、箱子、物品、状态、照片、文件清单与 SHA-256 完整性校验值。

只有在用户主动打开系统分享、打印、文件选择或邮件等功能并选择目标后，相关文件才会离开本应用。接收人、存储位置、打印服务、邮件服务或其他第三方应用将按照其自身隐私规则处理文件。分享前请检查是否包含住址、贵重物品、照片或其他不希望披露的内容。

恢复备份会在校验通过后，用备份中的项目、箱子和照片替换设备上的现有应用数据；本应用会在开始前要求用户确认。

07

信息保留与删除

本地记录会保留到用户删除相应箱子或项目、恢复另一份备份，或卸载本应用。删除箱子或项目时，本应用会一并移除其管理的照片副本。归档项目仅改变显示状态，不等同于删除。

已经导出、打印、存入其他位置或分享给第三方的 CSV、PDF、PNG、备份和其他副本不再由本应用控制，需要用户在相应位置或第三方服务中另行删除。

08

系统服务、第三方组件与网站数据

本应用使用 Flutter 及系统能力实现相机、照片选择、扫码、语音识别、文件选择、打印、分享和打开网页/邮件。当前版本未集成广告或行为分析 SDK。用户选择的操作系统服务或第三方应用可能按照各自的隐私政策处理相关数据。

本官网为静态 HTML 页面，不提供账号、表单、广告或分析脚本，也不设置产品跟踪 Cookie。网站仅使用浏览器本地存储记住中文/英文选择。网站传输过程中，网络基础设施可能为页面传输、安全维护和故障排查自动处理 IP 地址、访问时间、请求路径与 User-Agent 等标准连接日志；本站不使用这些信息建立用户画像。

09

安全措施与政策变更

本应用使用操作系统应用沙箱隔离本地数据，备份恢复前检查格式、路径、文件大小、清单和 SHA-256 校验值，并尽量减少网络数据路径。但任何存储方式都无法保证绝对安全，请保护设备密码并谨慎选择备份与分享目的地。

如果本应用的功能、权限、第三方组件或数据处理方式发生变化，我们会更新本政策并修改顶部的“最后更新”日期。重大变化会在适当位置提供更明显的提示。

01

Scope

This privacy policy applies to Moving Box (the “App”) and its static product website. “We” means the developer or operator whose confirmed details must be added under Contact before publication.

The App helps people create moving projects and box records, take or choose box photos, maintain item and location details, generate QR labels, advance move status, search offline, and export or back up records.

The current version requires no account, offers no developer-operated cloud sync, and includes no advertising, behavioral analytics, or third-party AI service. Core moving records stay on the user’s device by default.

03

Use and local storage

The App handles the information above on device to create, edit, search, and display moving projects and box records; assign a unique code within each project; maintain items, rooms, locations, move status, and issues; generate QR, PNG, CSV, and PDF files; and create, validate, or restore a local backup.

Structured records are stored as JSON snapshots in the App support directory. Writes use a temporary file and retain the previous local snapshot. Photo copies live in an App-managed directory. “Backup” here means a local file mechanism, not automatic cloud backup or developer-server synchronization.

04

System permissions

▣

Camera

Used only when you choose to take a box photo or scan a QR label in the App’s format. If denied, photo selection, manual entry, and text search remain available.

▧

Photos

Used only when you choose photos for a box through the system photo picker. Selected images are copied into the App’s private directory.

◉

Microphone

Used only after you start voice entry so the system speech service can produce editable text. The App does not retain the raw recording.

⌁

Speech recognition

Requested only when you choose voice entry. If denied or unavailable, you can switch directly to manual text entry.

The current iOS configuration does not declare location, contacts, notifications, or cross-app tracking permissions. Android currently declares camera, audio-recording, and internet permissions; the core record workflow does not therefore automatically upload projects, boxes, photos, or item lists to developer servers.

05

Speech recognition

The App requests the system’s on-device recognition mode, but actual support varies by device, operating system, language, and speech-service provider. We cannot promise that every recognition session is entirely offline. The operating system or the speech provider installed on the device may handle audio and recognition results under its own privacy policy.

The App itself does not retain raw audio. Recognized words appear as editable text first and are written to local data as a box note only after you confirm record creation. If speech is unavailable, camera, manual entry, search, QR, and other core features still work.

06

Export, printing, backup, and sharing

QR PNG files, single or A4 label PDFs, project closeout PDFs, CSV files, and versioned ZIP backups are generated on device. A full backup can contain projects, boxes, items, status, photos, a file manifest, and SHA-256 integrity values.

A file leaves the App only after you actively open a system sharing, printing, file-selection, or email flow and choose a destination. The recipient, storage location, print service, mail service, or other third-party app then handles that file under its own privacy rules. Before sharing, check for addresses, valuable belongings, photos, or anything else you do not want to disclose.

After validation succeeds, restoring a backup replaces the current App projects, boxes, and photos on the device with the backup contents. The App asks for confirmation before the restore begins.

07

Retention and deletion

Local records remain until you delete the relevant box or project, restore another backup, or uninstall the App. When a box or project is deleted, the App also removes its managed photo copies. Archiving a project changes visibility but is not deletion.

CSV, PDF, PNG, backup, print, or other copies that have already been exported, stored elsewhere, or shared with a third party are outside the App’s control and must be deleted separately from the relevant location or service.

08

System services, third-party components, and website data

The App uses Flutter and system capabilities for the camera, photo selection, scanning, speech recognition, file selection, printing, sharing, and opening web or email destinations. The current version includes no advertising or behavioral analytics SDK. An operating-system service or third-party app you choose may handle related data under its own privacy policy.

This website is static HTML with no account, form, advertising, or analytics script, and it sets no product-tracking cookies. It uses browser local storage only to remember your Chinese/English choice. During site delivery, network infrastructure may automatically process standard connection logs such as IP address, access time, request path, and User-Agent for page delivery, security maintenance, and troubleshooting. This site does not use that information to build user profiles.

09

Security and policy changes

The App uses the operating system’s application sandbox to isolate local data. Before a restore, it validates format, path safety, file size, manifest entries, and SHA-256 values, and it keeps network data paths limited. No storage method can guarantee absolute security, so protect your device passcode and choose backup and sharing destinations carefully.

If App features, permissions, third-party components, or data handling change, we will update this policy and revise the “Last updated” date above. Material changes will receive a more prominent notice where appropriate.
